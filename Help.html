SciCalc — Scientific Calculator for Autodesk Fusion

Version 1.1.0  •  Help Documentation

Overview

SciCalc is a fully-featured scientific calculator that lives inside Fusion as a docked panel. It reads geometry values directly from your active selection and lets you use those values straight in your calculations — no copying numbers between windows.

Click the Scientific Calculator button in the Inspect toolbar panel to open it. Close the panel with the X button; click the toolbar button again to reopen.

Calculator

Entering Expressions

  • Type directly on your keyboard or click the on-screen buttons
  • Click anywhere in the expression to position the cursor for inline editing
  • Bracket balance is shown in the display
  • Scientific notation is supported: 1.5e6 = 1,500,000

SHIFT Mode

Press SHIFT to access inverse and secondary functions: asin, acos, atan, sinh, cosh, tanh, log2, exp, and more.

Fix Decimal

Enter a number (0–12) in the Fix box to set decimal places. Leave blank for auto formatting. Click Auto to reset.

Display Options

  • Font size — adjust the result display size (12–48px)
  • Light / Dark — toggle theme
  • Compact / Full — hide or show advanced panels to save space

History Panel

  • Every calculation is saved automatically to history
  • Click the expression field to edit it inline
  • Click the note field to add a note
  • Press ↑ / ↓ in the main display to recall history entries
  • ★ Pin — pinned entries survive history clear
  • Run — re-evaluate the stored expression with current variables
  • Load — load the expression into the calculator display
  • Search — filter history by expression or note text
  • Clear — removes all unpinned entries
History is saved to history.json in the add-in folder and survives Fusion restarts.

Variables Panel

  • Click + Var to save the current result as a named variable
  • Give it a short name (e.g. r, len, k) — it then appears as a chip button
  • Click a chip to insert its value into the expression
  • Click x on a chip to delete it
Variables are saved to variables.json and are available every time you open Fusion.

Bookmarks Panel

  • Click + Bookmark to save the current expression
  • The name field defaults to Bookmark — click it to rename inline
  • Click the expression field to edit it inline
  • Use — loads the expression into the calculator display
  • x — deletes the bookmark

Quick Constants Panel

Pre-loaded physical and engineering constants including π, e, g (gravity), steel modulus, common material densities and more. Click any constant to insert its value into the expression.

Triangle Solver

Enter any 3 known values (sides a, b, c and/or angles A, B, C) and click Solve. The remaining values are computed using the Law of Sines and Law of Cosines.

  • Sides are in whatever unit you are working in (mm, m, etc.)
  • Angles are in the current angle mode (DEG / RAD / GRAD)
  • At least one side must be known for a unique solution
  • Click Use next to any result to insert it into the calculator
  • Click Clear to reset all fields
Only fields you have typed into are treated as known inputs. Computed fields are recalculated fresh on each Solve.

DMS ↔ Decimal Degrees

Convert between degrees/minutes/seconds and decimal degrees.

  • D° M′ S″ → Decimal: enter degrees, minutes and seconds, click Calc
  • Decimal → D° M′ S″: enter decimal degrees, click Calc
  • Negative angles: enter a negative value in the degrees field

Polar ↔ Rectangular

Convert between polar (r, θ) and rectangular (x, y) coordinates. Angles use the current angle mode (DEG / RAD / GRAD).

  • Polar → Rect: enter r and θ, click Calc to get x and y
  • Rect → Polar: enter x and y, click Calc to get r and θ
  • Click Use x, Use y, Use r or Use θ to insert into the calculator

Vector Maths Panel

Perform 3D vector operations on two vectors A (x, y, z) and B (x, y, z).

Filling Vectors from Selection

Select a vertex or sketch point in Fusion — its world X, Y, Z coordinates automatically fill into the active target vector (A or B). Click to A or to B to choose which vector receives the next selection. A brief filled A confirmation appears when values are loaded.

Selection Values Panel

SciCalc automatically reads your active Fusion selection every 0.4 seconds and displays the relevant geometry values. Click Use next to any row to insert that value into the calculator expression.

Persistent Data

The following files are stored in the SciCalc add-in folder and survive Fusion updates:

FileContents
history.jsonCalculation history with notes and pin state
variables.jsonNamed constants

When updating SciCalc, replace only SciCalc.py, calculator.html and the icons folder. Do not replace these data files — they contain your saved data.

Troubleshooting

IssueSolution
Calculator does not open on toolbar clickGo to Tools → Scripts and Add-Ins, find SciCalc, click Run
Selection Values panel shows nothingSelect an entity in the Fusion canvas. The panel updates every 0.4s.
History or variables missing after updateEnsure history.json and variables.json were not overwritten — restore from backup if needed
Panel layout looks wrongTry toggling Compact / Full mode, or adjusting the panel width
Calculation shows ErrorCheck brackets are balanced. The display highlights the error position in red.

Tips & Tricks

  • Select a face, then click Use on its area — immediately usable in a stress calculation
  • Hold a result in a Variable (e.g. k) and use it across multiple calculations
  • Use ans in an expression to chain calculations: ans * 1.15
  • Select two vertices to get the distance between them instantly
  • Switch to Compact mode when you only need the calculator pad and selection values
  • Pin important history entries with ● so they survive history clear
  • Use Bookmarks to save formulas you use repeatedly, e.g. a safety factor formula
  • The Vector Maths panel uses the current angle mode (DEG/RAD/GRAD) for the angle operation
