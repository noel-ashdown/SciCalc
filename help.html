SciCalc -- Scientific Calculator for Autodesk Fusion

Version 1.2.0  •  Help Documentation

Overview

SciCalc is a fully-featured scientific calculator docked inside Autodesk Fusion as a panel. It reads geometry values directly from your active selection and lets you use those values straight in your calculations.

Click Scientific Calculator in the Inspect toolbar to open it. Close with the X button; click the toolbar button again to reopen.

The Selection Values panel sits directly below the keypad for quick access. All extended panels (geometry, conversions, engineering) are collapsible to save space.

Calculator

Entering Expressions

  • Type directly on your keyboard or click the on-screen buttons
  • Click anywhere in the expression to position the cursor for inline editing
  • Bracket balance is shown in the display — unmatched brackets highlighted red
  • Scientific notation: 1.5e6 = 1,500,000
  • ans inserts the last result into the expression

History Panel

  • Every calculation saved automatically (last 50 entries)
  • Click expression or note field to edit inline
  • ↑ / ↓ arrows in display scroll through history — wraps around continuously
  • Pin — pinned entries (gold dot) survive Clear
  • Run — re-evaluate the stored expression
  • Load — load expression into the display for editing
  • Search — filter entries by expression or note text
  • Clear — removes all unpinned entries
  • Save CSV — writes history as a timestamped CSV file to the SciCalc folder (history_export_YYYYMMDD_HHMMSS.csv). Columns: Expression, Result, Note.
History is saved to history.json between sessions.

Variables Panel

  • Click + Var to save current result as a named variable
  • Click a chip to insert its value into the expression
  • Click x on a chip to delete it
Saved to variables.json between sessions.

Bookmarks Panel

  • Click + Bookmark to save current expression with a name
  • Click name or expression field to edit inline
  • Use -- loads expression into calculator
Saved to bookmarks.json between sessions.

Triangle Solver

The diagram shows the convention: side a is opposite angle A, side b opposite B, side c opposite C.

  • Enter any 3 known values (sides a, b, c and/or angles A, B, C) and click Solve or press Enter
  • At least one side must be known for a unique solution
  • Angles use the current angle mode (DEG / RAD / GRAD)
  • Click Use next to any result to insert into the expression
  • Red Clear button resets all fields
Only fields you have typed into are treated as known inputs.

Circle Geometry

The diagram shows radius (r), diameter (d), arc, sector and circumference C = 2*pi*r.

r, d, area or circumference -- enter any one, all others computed.

Arc length or sector area -- enter radius + central angle in current angle mode.

Click Use next to any result to insert into the expression. Red Clear resets all fields.

DMS / Decimal Degrees

  • D M S to Decimal: enter degrees, minutes, seconds, click Calc
  • Decimal to D M S: enter decimal degrees, click Calc
  • Negative angles: enter negative value in the degrees field

Polar / Rectangular

Angles use the current angle mode (DEG / RAD / GRAD).

  • Polar to Rect: enter r and angle, click Calc to get x and y
  • Rect to Polar: enter x and y, click Calc to get r and angle
  • Use x, Use y, Use r, Use angle buttons insert results into expression

Persistent Data

The following files are stored in the SciCalc add-in folder and survive Fusion updates:

FileContents
history.jsonCalculation history with notes and pin state
variables.jsonNamed constants
settings.jsonTheme, font size, Fix decimal, compact mode, open panels
bookmarks.jsonSaved named expressions
When updating SciCalc, replace only SciCalc.py, calculator.html, help.html and the icons folder. Do NOT replace the .json data files -- they contain your saved data.

ANS Hint

A small ANS = indicator appears in the top-right of the display area showing the current value of ANS at all times. This updates every time a calculation completes so you always know what value will be inserted by the ANS button.

History Wrap-Around Navigation

Pressing ↑ scrolls back through history. When you reach the oldest entry pressing ↑ again wraps back to a blank expression. Pressing ↓ scrolls forward and when the display is already blank pressing ↓ wraps to the most recent entry. You can cycle continuously in either direction.

Save History to File

The Save button in the History panel writes the full history as a timestamped CSV file directly to the SciCalc add-in folder. The file is named history_export_YYYYMMDD_HHMMSS.csv and contains Expression, Result and Note columns. The CSV button copies the same data to the clipboard instead.

Auto-Insert Selection Values

The Selection Values panel has an auto checkbox in its header.

  • Unticked (default) — click the Use button to insert a value into the expression
  • Ticked — click directly on the value text to insert it immediately, without needing the Use button

This is a convenience shortcut when working quickly with geometry measurements. The Use button always works regardless of the auto setting.

Copy All Selection Values

The copy all button in the Selection Values panel copies every current measurement to the clipboard as a tab-separated label/value table, ready to paste into a spreadsheet or document.

Keyboard Shortcuts Panel

A collapsible Keyboard Shortcuts panel lists all keyboard shortcuts and button actions for quick reference without leaving Fusion. Open it using the chevron (▼) in the panel header.

Diagrams

The Triangle, Circle, Polar/Rect and DMS panels each have a Show diagram button that expands a labelled diagram for reference. The diagrams are collapsed by default to save space. The Beam Section panel diagram updates automatically when you change the section type and includes the relevant Ixx formula.

Reciprocal (1/x)

The 1/x button (normal mode) inserts 1/( ready for you to enter the denominator, then close with ).

Example: 1/x → type 8 → ) → = gives 0.125.

In SHIFT mode the same button becomes n! (factorial). Example: SHIFT → n! → type 5 → ) → = gives 120.

Last-Used Panel

SciCalc remembers which panel you last opened using its chevron and scrolls to it automatically when the calculator reloads. This is saved as part of the settings file.

Tips and Tricks

  • Select a face, then click Use on its area -- immediately usable in a stress or load calculation
  • Hold a result in a Variable (e.g. k) and use it across multiple calculations
  • Use ans to chain calculations: ans * 1.15
  • Select two parallel faces to get the distance between them instantly
  • Select a partial cylindrical face to get its arc angle
  • Switch to Compact mode when you only need the keypad and selection values
  • Pin important history entries so they survive history clear
  • Use Bookmarks to save formulas you use repeatedly
  • Type M6 or 1/4 in the bolt search box to quickly filter the thread list
  • Press Enter in any Triangle Solver field to trigger Solve immediately
  • Use the CSV button in History to export all calculations to a spreadsheet
  • Panel open/close state is saved -- your preferred layout is restored on reopen
